How to read this report

Each point is the median CPU time from repeated runs. The table shows every measured run. Compare containers or engines at the same key count, workload, and build. Node search and whole-tree lookup are separate suites; their times measure different operations. Build flags, CPU conditions, and query distribution affect results.
