How to read this report

Each point is the median CPU time from repeated runs. The table shows every measured run. Compare containers or engines at the same key count, workload, and build. Insertion times are normalized by batch size and exclude construction and destruction of the container. Node search and whole-tree operations are separate suites. Build flags, CPU conditions, and query distribution affect results.
