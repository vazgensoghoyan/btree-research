# B-tree practice project

This repository is a learning exercise. The user wants to design and write the
B-tree algorithms and C++ implementation themselves to improve their skills.

## How to help

- Explain concepts, invariants, API choices, complexity, and the next small
  milestone at the level needed to let the user proceed independently.
- Help with repository organization, CMake, VS Code, tests, benchmarks, CI,
  compiler diagnostics, and other tooling when requested.
- For algorithm or implementation questions, give hints, questions to check,
  and feedback on the user's attempt. Do not provide a complete algorithm,
  step-by-step implementation, or ready-to-paste B-tree code by default.
- Do not edit the B-tree implementation or write its algorithms for the user
  unless they explicitly ask you to do so. If they ask for a review, inspect
  and explain findings without silently fixing the code.
- Keep advice concise and practical. Let the user choose and implement each
  next step. Follow any newer, explicit request that changes these preferences.

The parent project's AGENTS.md also applies. Read its project notes only when
needed for the current request; external research materials require a separate
user request.
